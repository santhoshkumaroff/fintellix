## What past candidates report about Fintellix interviews

- Glassdoor rates difficulty **Average**, experience **mostly positive**. Most candidates came through campus (39%) or agencies (28%).
- Older fresher reports: **aptitude round** (speed/time/distance, partnership, data interpretation; cut-off is high), then **coding**, then **2–3 technical face-to-face rounds**. Every round is a knockout.
- Repeated tip: **"Mainly focuses on the resume"** and **"starts from basics and goes to advanced."** Expect each answer to get a follow-up "why?" or "what if?"
- The questions on file are mostly 2017–2019 developer hiring. This GenAI intern role is new (it names Claude, RAG and evaluation), so expect project deep-dives on **RAG / document Q&A / automation**.

### Likely round structure (prepare for all of them)
1. **Online test:** aptitude + Python MCQs + 1–2 easy coding problems → `12_Aptitude_and_Coding_Round`
2. **Technical 1:** Python, Pandas, SQL basics, live coding → folders 03, 04, 07
3. **Technical 2:** GenAI concepts + **your project in depth** → folders 05, 10
4. **Managerial/HR:** why Fintellix, why banking, learning attitude, 9-month commitment, WFO → folders 01, 11

## How to use each answer
Every question has: **Answer** (what to say) → **Example 1 / Example 2** (real-world examples, usually from banking) → sometimes an **Interview tip**. Say the answer in your own words, then give **one** example. Keep the second example in reserve for the follow-up.

> Honest note: no prep kit can guarantee a selection. These files cover everything the JD lists, plus what past candidates were asked. What gets you selected is (1) a project you actually built and can debug live, (2) clear Python/Pandas basics, and (3) real curiosity about banking data. Do the hands-on exercises; don't only read.
